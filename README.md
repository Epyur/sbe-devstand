# Стенд разработки (sbe-devstand)

Плагин-стенд для разработки SBE-плагинов **вне реестра ЦУП**. Пока ваш плагин не
зарегистрирован, он может:

- читать и генерировать на **боевых** LLM, Базе знаний и почте через центральный
  шлюз `dev-gateway` (только чтение);
- отрабатывать запись на **локальном** сервисе, поднятом в Docker.

Плагин не имеет своего сервера и ставится вручную (в реестр не входит).

## Установка

1. Склонируйте репозитории рядом в папку плагинов Obsidian:
   - `sbe-core` — ядро системы (нужно для сборки);
   - `sbe-devstand` — этот плагин.
   Адрес папки плагинов обычно `<вольт>/.obsidian/plugins/`.
2. В `sbe-devstand`: `npm install && npm run build`.
3. В Obsidian включите плагин в «Сторонние плагины».
4. Попросите администратора выдать вам роль в приложении «Стенд».

## Как пользоваться из своего плагина

```ts
import { getService } from '../sbe-core/src/bridge';

const dev = await getService('sbe-devstand');
const me = await dev.whoami();               // { email, role, services }
const text = await dev.llm.complete(system, user);
const found = await dev.kb.search('фасад');
const mail = await dev.mailer.pull();
const local = dev.local;                     // { url, token } — для записи
```

Запись в боевые сервисы запрещена: шлюз раздаёт только read-ручки. Данные
пишутся в локальный сервис (комплект `sbe-devstand-kit`), пока плагин вне
реестра. После регистрации в реестре плагин работает в боевом контуре сам.

Настройки плагина: адрес стека, включённые интеграции, адрес и токен локального
сервиса.

Подробное руководство — `docs/sbe-devstand-guide.md` в репозитории вольта.
